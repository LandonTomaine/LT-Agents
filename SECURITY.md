# Security Policy

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability.

Report security concerns privately to the repository owner through GitHub:

- Open the repository's **Security** tab and use private vulnerability reporting when available.
- If private reporting is unavailable, contact the owner directly before sharing details publicly.

## Supported Versions

This repository publishes the current `main` branch as the supported skill catalog.

## Scope

Security-sensitive issues include exposed credentials, unsafe install instructions, unsafe helper scripts, or guidance that could cause destructive actions without explicit approval.
